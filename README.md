# Граф знаний для проверки совместимости модификаций для игры Minecraft

## Компетентностные вопросы
1. Какие пары модов имеют релизы под одну версию Minecraft и один загрузчик, но явно несовместимы друг с другом?
2. Какие релизы подходят под выбранную версию Minecraft и загрузчик, но требуют моды, для которых подходящих релизов в графе нет?
3. У каких модов различаются зависимости релизов для Forge и Fabric одной версии Minecraft?
4. Какие пары релизов не имеют прямого конфликта, но один требует мод, с которым несовместим другой?
5. Какие моды размещены на Modrinth, но требуют зависимости, которые доступны только на CurseForge?
6. Какие пары модов связаны открытым тикетом о совместимости, но не имеют явно записанной несовместимости?
7. Для каких пар модов открытые сообщения о совместимости есть в репозиториях обоих проектов?
8. Какие разработчики одновременно разрабатывают мод и хотя бы одну его зависимость?
9. Какие моды не имеют релиза под нужный патч Minecraft, но имеют релизы под другие патчи той же ветки с тем же загрузчиком?
10. Какие релизы под выбранную версию Minecraft зависят от модов, в репозиториях которых открытых баг-репортов больше, чем закрытых?

## Сборка графа

```bash
python -m venv .venv
.venv/Scripts/activate           # source .venv/bin/activate
pip install -r requirements.txt

python util/parse.py
python util/build.py
```

## Структура проекта

| Файл | Назначение |
|------|------------|
| `graph/ontology.ttl` | онтология (схема): классы, свойства, аксиомы |
| `graph/graph-example.ttl` | онтология с небольшим набором примеров экземпляров |
| `graph/graph-full.ttl` | полный граф, собранный по данным из `data/` |
| `util/parse.py` | выгрузка данных из API CurseForge, Modrinth и GitHub в `data/` |
| `util/build.py` | точка входа: сборка, вывод, проверка и сохранение графа |
| `src/sources.py` | чтение сырых JSON в промежуточные модели (`src/models.py`) |
| `src/versions.py` | нормализация версий Minecraft и загрузчиков |
| `src/resolve.py` | слияние одного мода с разных платформ, привязка репозиториев |
| `src/issues.py` | тип тикета (баг / совместимость) и упоминаемые в нем моды |
| `src/builder.py` | генерация триплетов по онтологии |
| `src/namespace.py` | пространство имен и правила построения идентификаторов |
| `src/schema.py` | загрузка схемы онтологии |
| `src/reasoning.py` | материализация новых фактов из свойств и наследований |
| `src/validate.py` | проверка графа на аксиомы онтологии |
| `src/store.py` | сохранение и загрузка графа |
| `src/config.py` | хранение конфигурационных данных |
